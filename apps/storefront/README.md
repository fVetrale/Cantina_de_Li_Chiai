# Cantina de Li Chiai — Storefront (`@winery/storefront`)

E-commerce storefront for Cantina de Li Chiai built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Development

Run development server from the monorepo root:
```bash
pnpm --filter @winery/storefront dev
```

Or directly inside `apps/storefront`:
```bash
pnpm dev
```

The application will be accessible at [http://localhost:3000](http://localhost:3000).

## Scripts

- `pnpm dev`: Start Next.js development server
- `pnpm build`: Build production bundle
- `pnpm start`: Start production server
- `pnpm lint`: Run ESLint checks
- `pnpm typecheck`: Run TypeScript type check (`tsc --noEmit`)
